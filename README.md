# 流浪猫的避难所 (Stray Cat's Sanctuary)

一个部署在 GitHub Pages 的个人博客，基于 [Hexo](https://hexo.io/zh-cn/)。

<https://xuzhunzhi.github.io/>

## 写文章

在 `source/_posts/` 下新建 `.md` 文件，带 front-matter：

```markdown
---
title: 标题
date: 2026-08-20 00:00:00
categories: [分类]
tags: [标签]
---
正文
```

然后 `git add . && git commit -m "post" && git push`，GitHub Actions 会自动构建发布。
